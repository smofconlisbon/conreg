# Field Options and Add-ons

## Data structures

| Feature | Table | Config area |
|---|---|---|
| Field options | `conreg_member_options` | `conreg_options.option_groups/options` |
| Add-ons | `conreg_member_addons` | Event add-on config and admin form |

## Builder routes

- `conreg_config_addons` for add-on definitions.
- Option groups are configured in event settings and consumed by forms/reports.

## Related admin/report routes

- `conreg_admin_member_options`
- `conreg_admin_member_addons`
