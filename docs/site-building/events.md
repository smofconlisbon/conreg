# Events and Cloning

## Event admin routes

| Route | Purpose |
|---|---|
| `conreg_event_list` | List and manage events |
| `conreg_event_clone` | Clone config into a new event |
| `conreg_config` | Main event configuration |

## Builder workflow

1. Create baseline event settings.
2. Clone for next cycle if needed.
3. Adjust membership types/classes and payment settings per event.
4. Review dynamic event links generated by `EventsMenuDeriver`.

## Config scope

Each event stores independent values in `conreg.settings.{eid}`.
