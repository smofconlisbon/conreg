# Badges (`conreg_badges`)

## What it adds

| Area | Details |
|---|---|
| Routes | `conreg_badges_list`, `conreg_badges_list_export`, `conreg_badges_print` |
| Permission | `view membership badges` (+ member type variant) |
| Dynamic menu | `BadgesMenuDeriver` |

## Libraries

Badges features depend on assets from `conreg.libraries.yml`, including:

- `js/textFit.min.js`
- `js/html2canvas.min.js`
- `js/jquery.badge_names.js`

## Usage

Badge tools are read/export/print views over member data and badge-name fields.
