# Check-in and Fan Table

## Routes

| Route | Purpose |
|---|---|
| `conreg_admin_checkin` | Convention arrival check-in |
| `conreg_admin_fantable` | Fan table workflow for onsite registration |
| `conreg_fantable_register` | Fan table registration variant |
| `conreg_fantable_checkout` | Fan table checkout variant |

## Operational scope

- Check-in updates attendance status fields.
- Fan table flow supports staff-assisted signup and follow-up actions.
