# Reporting and Exports

## Reporting routes

| Route | Output |
|---|---|
| `conreg_admin_member_list` | Full member details list |
| `conreg_admin_member_summary` | Membership summary |
| `conreg_admin_child_member_ages` | Child age report |
| `conreg_admin_member_options` | Option selections |
| `conreg_admin_member_addons` | Add-on selections |
| `conreg_admin_mailout_emails` | Mailout list view |
| `conreg_admin_mailout_emails_export` | Mailout export output |

## Access model

Each report path is permission-gated (`view membership *`, `manage mailout
lists`, and dynamic option permissions).
